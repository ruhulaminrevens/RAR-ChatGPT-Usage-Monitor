# Privacy

RAR ChatGPT Usage Monitor is a local browser extension.

- It does not ask for your ChatGPT password, OpenAI API key, session token, email, or payment information.
- Usage values are read from the ChatGPT Usage panel rendered in your own logged-in browser session.
- Last usage values, widget position, alert preferences, and version-check state are stored in `chrome.storage.local`.
- Optional version checks fetch only the public `version.json` file from this GitHub repository.
- The extension does not send your ChatGPT conversations or usage values to the project author.
